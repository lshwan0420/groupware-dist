# 그룹웨어 — 배포

**사내망 그룹웨어**의 Windows 설치 파일과 자동 업데이트 피드를 제공하는 저장소입니다.
소스 코드는 비공개 저장소에 있습니다.

## 다운로드

**[⬇ 최신 설치 파일 바로 받기 (groupware-setup.exe)](../../releases/latest/download/groupware-setup.exe)**

버전별 변경 내용과 이전 버전은 [릴리즈 목록](../../releases)에서 볼 수 있습니다.

| 파일 | 용도 |
|---|---|
| `groupware-setup.exe` | 최신 설치 파일 (위 링크와 같은 파일, 이름만 고정) |
| `groupware-{version}-setup.exe` | 설치 파일 (관리자 권한 불필요, 자동 업데이트 지원) |

`latest.yml` 과 `.blockmap` 은 `electron-updater` 가 쓰는 파일입니다. 직접 받을 필요 없습니다.

## 이 앱은

사내망(192.168.x.x)에서 쓰는 연습용 그룹웨어입니다. 서버 역할을 할 PC 한 대에 설치하면
내장 데이터베이스와 웹 서버가 함께 실행되고, 같은 사내망의 다른 PC는 브라우저로 접속합니다.

- **게시판** — 공지사항·자유게시판·자료실, 검색·댓글·첨부파일
- **일정** — 월간 달력, 개인·부서·전사 공개 범위
- **전자결재** — 기안 → 순차 승인/반려, 회수
- **조직도** — 부서 트리, 직원 검색
- **메신저** — 1:1·그룹 대화, 실시간 수신, 읽음 표시
- **관리** — 사용자·부서·게시판

Windows 10/11 x64 전용입니다. 코드 서명이 없어 SmartScreen 경고가 뜨면 **추가 정보 → 실행** 을 눌러 주세요.
데이터(DB·첨부파일)는 `%APPDATA%\groupware` 에 저장되며 업데이트·삭제해도 유지됩니다.
